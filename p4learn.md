# P4 Training & Learning Resources

## Hands-on Labs (No Hardware Required)

- **[p4lang/tutorials](https://github.com/p4lang/tutorials)** — Official hands-on exercises using BMv2 + Mininet. Progressive modules: basic IPv4 forwarding, tunneling, P4Runtime control plane, firewalling, link monitoring, flowcache
- **Pre-built VM** available for VirtualBox (Intel/AMD and Apple Silicon) with the full toolchain installed

## Software Tools for Learning

- **BMv2 (Behavioral Model v2)** — Software P4 switch implementing `v1model`. Repo: [p4lang/behavioral-model](https://github.com/p4lang/behavioral-model)
- **Mininet** — Creates virtual network topologies with BMv2 as the switches
- **p4c** — Reference P4 compiler
- **p4runtime-shell** — Interactive Python shell for controlling P4 switches via P4Runtime/gRPC
- **ptf** — Packet test framework for writing switch tests
